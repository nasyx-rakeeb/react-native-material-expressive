# Specs

Machine-readable spec extracts live here: one JSON file per component (plus `tokens.json` and `typography.json`) generated by `tools/extract-tokens` on Day 2.

**Rule:** no value enters this directory from memory, a blog, a port, or a design kit. Every record must cite:

```jsonc
{
  "token": "FilledButton.ContainerHeight",
  "value": 40,
  "unit": "dp",
  "source": "tokens/FilledButtonTokens.kt:31",
  "sourceVersion": "material3:1.5.0",
  "sourceSha256": "d389bb542a1637dc202e715b279a178be1b0d51886234fe2810a92427c07b2a6"
}
```

Behavioral facts that tokens cannot express (layout rules, state transitions, spring routing, content-padding formulas, min sizes, a11y semantics) belong in a sibling `*.behavior.md` with Compose file:line citations.

Anything unsourced is recorded in `../UNVERIFIED.md` and blocks the component's DONE cell. Generated token TypeScript must come from these files; CI fails on drift.

Day 0 created this directory but no specs — extraction starts Day 2.
