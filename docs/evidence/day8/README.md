# Day 8 — motion scheme, spring driver, reduce motion

Day 8 delivers the Material3 1.5.0 motion layer and its evidence. It does not
ship a component; components consume this layer from Day 11 onward.

- **Status:** work complete; Day 8 Day-Close Report posted, awaiting approval.
- **Decisions:** ADR-015 (Compose-exact spring driver), ADR-016 (reduce-motion
  mapping). ADR-017 (U-32) was decided during the same session and is a Day 7
  follow-up, not part of Day 8.

  `apps/reference-compose/.../SpringGoldenTest.kt` through the public
  `MotionScheme` API. Nothing is copied from documentation.

## Why not Reanimated `withSpring` (ADR-015)

Reanimated 4.7.1 uses the same closed form but an energy-ratio stop (`6e-9`)
instead of Compose's 0.01 displacement threshold plus estimated duration.

| Worst cases | Compose | Reanimated 4.7.1 | Deviation |
|---|---:|---:|---:|
| `fastEffects` (both schemes) | 107 ms | settles 217 ms | **1.512%** (fails 1% gate) |
| `defaultEffects` | 165 ms | settles 317 ms | 0.906% |
| `defaultSpatial` (standard) | 228 ms | settles 450 ms | 0.577% |
| `fastSpatial` (standard) | 161 ms | settles 317 ms | 0.869% |

Every token settles later than Compose, roughly 2×. The shipped driver samples
the Compose solver per frame and clamps at the Compose duration. The full
12-row comparison is in `springs/verification.md`.

## Reduce motion (ADR-016)

- `spatial` → instant; `effects` → 100 ms linear fade (`MotionDurations.short2`).
- `useReduceMotion` reads `AccessibilityInfo.isReduceMotionEnabled`, listens for
  `reduceMotionChanged`, and accepts an override for previews/tests.
- Covered by the "reduce-motion mapping" tests in `src/motion/__tests__/spring.test.ts`.

## Limits and open items

- The driver is verified numerically off-device. Jest cannot run Reanimated's
  UI-thread runtime, so a Reanimated upgrade still needs the gallery smoke test
  (ADR-015 lists the failure modes).
- The screenshots prove the UI and the reduce-motion status text, not frame
  timing. Motion frame times are not a Day 8 exit criterion; `U-29` remains the
  open physical-device performance item and a hard blocker before Day 31/32.
- Reduce motion has no Compose counterpart to diff against; it is a platform
  mapping, tested by unit tests and the gallery, not by the pixel gate.
- `U-32` was resolved during this session (ADR-017). `ShapeContainer` is
  decorative-only; interactive containers use `borderRadius`.
