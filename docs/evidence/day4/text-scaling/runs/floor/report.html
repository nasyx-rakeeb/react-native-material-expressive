What this establishes

  • The capture, crop, compare, and report pipeline is deterministic across repeated launches and cold boots.
  • Compose and React Native agree exactly on solid fills, rounded-rectangle geometry, and elevation shadows on this profile.
  • Text from the same Roboto Flex file differs only in rasterization: Measured text layout: Compose 402.0×73.0 px, React Native 402.0×73.0 px. The difference is confined to the glyph edges.
  • No threshold is proposed here. Day 3 is a measurement, not a gate change.

What this does not establish

  • It does not establish component parity; no library components exist yet.
  • It does not establish iOS behavior.
  • It does not establish that the 4 non-AA text pixels are acceptable. That is a product decision.
